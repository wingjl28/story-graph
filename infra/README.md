# Story Graph Infrastructure (AWS CDK)

This is a skeleton AWS CDK TypeScript project for deploying Story Graph to AWS App Runner.

## Quick Start

- **Setup:** `cd infra && npm install`
- **Synthesize:** `npm run synth`
- **Deploy** (after AWS credentials configured): `npm run deploy`
